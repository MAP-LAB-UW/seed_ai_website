# SEED AI Website

This repository contains the static project website for the SEED AI diagnostic assessment project.

The website presents three main components:

1. **Final Facets**
   Learning goal facets and misconception facets used in the diagnostic assessment.

2. **Selected Assessment Items**
   10 selected multiple-choice diagnostic assessment items.

3. **Q-Matrices**
   Option-level Q-matrices showing the relationship between each answer option and the corresponding learning goal or misconception facets.

## Project Structure

```text
seed_ai_website/
├── index.html
├── style.css
├── script.js
└── README.md
```

* `index.html` contains the main webpage structure.
* `style.css` controls the layout and visual appearance of the website.
* `script.js` stores the assessment items, Q-matrices, and interactive webpage behavior.
* `README.md` contains information about the project and website setup.

## Running the Website Locally

Because this is a static website, no backend server is required.

You can open `index.html` directly in a web browser.
